# My Watchlist+

## About the project

This is an overengineered watchlist for movies and series.

The goal is to keep the richness of a detailed personal media database without the friction of filling out a long form every time something is added. Instead, the system accepts lightweight natural-language input, uses an LLM to interpret it, and turns it into structured database entries.

Those entries are then enriched with accurate metadata from TMDB, while still leaving room for manual edits, personal notes, incomplete entries, and more detailed logging when needed.

In short: a watchlist that can be as quick as a note, but as structured as a database.
